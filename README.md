# TransitWatch

工程心理学课程作业：系外行星凌星检测的信号检测论交互实验。

## 运行方法

保持以下三个文件位于同一个文件夹：

- `index.html`
- `style.css`
- `script.js`

双击 `index.html` 即可在浏览器中运行，无需服务器或第三方库。

## 文件职责

- `index.html`：完整网页结构
- `style.css`：完整视觉样式
- `script.js`：教程、练习、正式实验、SDT计算、ROC与分布图交互逻辑

## GitHub Pages

上传三个文件到仓库根目录后，在 GitHub Pages 中选择 `main` 分支 `/ (root)` 即可部署。
